# stats — 个人开发统计

递归扫描指定目录下的所有 Git 仓库，聚合个人开发统计：提交数、活跃天数、连续提交天数、活跃时段热力图、活跃仓库排名、语言分布。

## 基本用法

```bash
byte-git stats                          # 统计当前目录下所有仓库（默认当前 git 用户）
byte-git stats --author 张三             # 指定作者
byte-git stats --days 30                # 最近 30 天
byte-git stats --dir ~/code             # 扫描指定目录下的所有仓库
```

## 参数

| 参数 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `--dir` | string | `.` | 扫描目录（递归查找其下所有 Git 仓库） |
| `--days` | int | `0` | 统计天数（`0` = 全部历史） |
| `--author` | string | `""` | 作者名称（默认读取当前 git 用户名） |

## 输出内容

- **总览**：总提交数、活跃天数、当前连续、最长连续
- **提交热力图**：按年的每日提交格子图（终端彩色渲染）
- **活跃时段**：按小时分布的提交活动
- **仓库排名**：贡献最多的仓库列表
- **语言分布**：按文件类型统计的代码分布
